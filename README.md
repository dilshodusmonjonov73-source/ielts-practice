# IELTS Practice

An IELTS practice platform that simulates the real exam experience. Take full-length Reading tests under timed conditions, get instant grading, and review your mistakes.

> **Status:** In development. The Reading module is being built first; Listening, Writing and Speaking are planned.

## Features

### Reading
- Full tests with **40 questions** and a countdown timer
- Original passages (first topic: ecology)
- Questions paraphrased at real IELTS difficulty, ordered by their position in the passage
- Text highlighting while you read
- **Automatic grading** that shows exactly which answers were wrong

### Planned
- Listening module (audio player, British-accent audio, transcript after the test)
- Writing practice (Task 1 and Task 2)
- Speaking practice
- Standalone desktop version (CD-style, with a main menu)
- Online version with separate Reading and Listening sections

## Getting Started

```bash
git clone https://github.com/dilshodusmonjonov73-source/ielts-practice.git
cd ielts-practice
```

Then open `index.html` in your browser.

## How a Test Works

1. Open the Reading section.
2. Start a test. The timer begins.
3. Answer all questions.
4. Submit to see your score, the correct answers, and where you made mistakes.
